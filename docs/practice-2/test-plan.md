# Тестовый план СМП

## Область тестирования

Все 11 сервисов системы: Gateway, Switch, Authorization, Card Management, Transaction Logger, Notification Service, Terminal Simulator, Merchant Simulator, Web Dashboard, плюс PostgreSQL и RabbitMQ.

**Подход:** risk-based

## Критерии входа

- `docker-compose up` поднимает все контейнеры без ошибок
- `GET /health` всех сервисов возвращает `status: ok`
- RabbitMQ Management UI доступен на `localhost:15672`
- PostgreSQL инициализирован (таблицы созданы)
- Пройдено smoke тестирование

## Критерии выхода

- Пройдено 100% тест-кейсов из ядра
- Нет открытых дефектов критического и высокого уровней
- Все сценарии critical path проходят без ошибок
- Покрытие pairwise-набора ≥ 95%

## Критерии приостановки

- Падение PostgreSQL или RabbitMQ (без них система неработоспособна)
- Не проходят health-check сервисов

## Критерии возобновления

- Восстановление инфраструктуры
- Подтверждение работоспособности smoke-набором

## Риски

| Риск                                                   | Вероятность | Мера                                                |
|--------------------------------------------------------|-------------|-----------------------------------------------------|
| Race condition при резервировании средств (см. ТЗ Auth) | Средняя     | Запускать параллельные транзакции, проверять баланс |
| RabbitMQ недоступен при публикации                     | Средняя     | Тестировать fallback → reversal (mti=0400)          |
| Дублирование RRN | Низкая | Проверка атомарного счётчика seq при совпадении timestamp |

## Метрики

- `% пройденных тест-кейсов` (целевое ≥ 95%)
- `Количество открытых багов` по severity (critical=0, high=0)
- `Pairwise coverage` (% покрытых пар значений)
- `Среднее время ответа` Gateway (целевое < 200ms)
