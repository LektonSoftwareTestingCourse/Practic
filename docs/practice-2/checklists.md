# Чек-листы СМП

## 1. Дымовое тестирование (Smoke)
- [ ] Все Docker-контейнеры запущены (11 сервисов + PostgreSQL + RabbitMQ).
- [ ] Эндпоинт `http://localhost:8080/health` возвращает 200 OK.
- [ ] RabbitMQ Management UI доступен.
- [ ] Gateway успешно проксирует запросы к внутренним сервисам.
- [ ] База данных PostgreSQL доступна для записи.

## 2. Критический путь (Critical Path)
- [ ] Генерация тестовых карт через API (`/api/cards/generate`).
- [ ] Запуск симулятора терминалов (`/api/simulator/terminal/run`).
- [ ] Проведение транзакции по сценарию "normal".
- [ ] Запись транзакции в Transaction Logger.
- [ ] Отображение транзакции на Web Dashboard (порт 3000).
- [ ] Проверка корректности списания средств с баланса карты.
